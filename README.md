# 다시, 한 생

**유재민 제작 · 한국어 역사 인생 시뮬레이터**

기원후 1~2000년 또는 중세 집중 모드(500~1500년)에서 무작위로 태어나, 현대의 기억 없이 0세부터 사망까지 살아가는 웹 게임입니다. 성공 조건이나 승패는 없습니다.

## 실행

Node.js 18 이상과 Python 3이 있는 환경에서:

```sh
cd /workspace/R1
npm start
```

포트 3000으로 정적 웹 서버를 실행합니다. 별도의 패키지 설치·API 키·데이터베이스가 필요 없습니다. `index.html`을 파일로 직접 열지 말고 HTTP 서버로 실행하세요. 외부 글꼴 연결이 안 되면 시스템 글꼴로 표시됩니다.

다른 경로에서는 저장소 루트에서 `python3 -m http.server 3000 --bind 0.0.0.0`으로 실행할 수 있습니다. 정적 호스팅에서는 저장소 전체를 배포 루트로 사용하면 됩니다.

## 플레이

- 첫 방문에는 7초에 한 해씩 자동 진행합니다. 속도를 바꾸거나 일시 정지·1년 보내기를 사용할 수 있습니다.
- 주요 사건에서는 시간이 멈춥니다. 선택을 마치면 자동 진행이 켜져 있을 때 다시 흐릅니다.
- 생활 집중(균형·생업·배움·가족·여가·건강)은 언제든 변경할 수 있습니다. 영유아 때는 양육 환경의 방향을 뜻합니다.
- 생활 활동과 직업 선택은 해마다 총 2회 할 수 있습니다. 조건을 만족하지 못한 활동에는 이유가 표시됩니다.
- 혼인 인연을 알아본 뒤 혼인할 수 있습니다. 출산은 확정적이지 않으며, 이사·별거·일부 시대의 법적 이혼·은퇴도 가능합니다.
- 능력치·연간 수입·생활비·재산 그래프·가족·생애 기록이 선택에 따라 바뀝니다.
- 새로고침하면 브라우저 저장소에서 복원하며 자동 진행은 멈춘 상태로 재개됩니다. 탭이 보이지 않거나 설정 창이 열리면 시간이 흐르지 않습니다.
- 설정에서 새로운 삶을 시작할 수 있습니다. 진행 중인 생애를 중단할 때는 확인 후 미완의 기록으로 남깁니다. 최대 30개 생애를 보관합니다.
- 생애 기록은 텍스트로 내려받을 수 있습니다. 서버 동기화는 없으며 브라우저 데이터를 지우면 저장도 사라집니다.

## 현재 수록 범위와 역사적 한계

- 12개 광역 지역, 72개 국가·정권 항목. 출생 연도에 존속하는 수록 항목 중 균등 추첨합니다. 세계 전체 국가나 인구 비율을 반영하지 않습니다.
- 38종 기본 직업, 64종 생활 활동. 시대·지역·나이·성별 관습·문해력·능력·재산·관계 등으로 조건을 제한합니다.
- 실제 연표 사건 33건, 지역·생활 장면 19종, 성장 단계 및 가족·직업에 따른 추가 사건. 개인 서사와 결과 확률·통계는 창작입니다.
- ‘0세기’는 사용자의 요청을 위한 게임 내 보조 명칭으로 기원후 1~99년을 뜻합니다. 공식 역사 세기 구분이 아닙니다. 1~20세기는 통상적 세기 구분을 사용합니다.
- 이름은 지역별 창작 이름 풀입니다. 모든 시대의 작명법과 신분별 성씨 사용을 완벽히 재현하지 않습니다. 지역별 법·카스트·노예제·혼인·교육·정확한 영토와 정권 계승 또한 단순화했습니다.
- 정권이 끝난 뒤 동일 광역 지역의 수록 정권으로 표시를 갱신합니다. 복수 정권이 공존하면 현재 정권이 존속하는 동안 유지합니다. 세부 영토·정권 데이터가 없으면 지역명으로 전환합니다.
- 지도는 대략적인 광역 지역 위치를 보여 주는 도식이며 역사적 국경이나 정확한 출생지를 표시하지 않습니다.
- 소득·재산은 비교용 게임 자원인 ‘살림 단위’로 표시합니다. 시대별 실제 화폐 가치나 계량경제 모델이 아닙니다. 토지 마련은 당대 관습 안의 사용권으로 단순화했습니다.
- 기록된 세계사의 큰 사건은 고정 연표를 따릅니다. 평판·재산을 모아 청원·구휼을 하면 마을 단위의 대체 역사를 남기고 위기의 피해를 줄일 수 있습니다. 국가 전체의 정치·전쟁·외교를 바꾸는 모델은 포함하지 않습니다.
- 사망할 때까지 출생 시대의 범위를 넘어 연도는 계속 흐릅니다. 수록 연표 밖에서는 일반 생활 사건이 이어집니다.

참고 사이트 `1in8b.life`는 조사 시 HTTP 403으로 직접 확인할 수 없었습니다. 설명된 플레이 흐름을 바탕으로 독립적인 화면과 게임 로직을 구현했습니다. `sites` 연결 도구는 이 환경에 제공되지 않아 외부 사이트로 게시하지 않았습니다.

## 검증

```sh
npm test
```

Node 내장 테스트로 시대별 출생·실제 존속 정권 배정·결정 시 시간 정지·행동 제한·혼인/출산/별거·직업/은퇴·실제 연표·저장 복원·100개 생애의 사망까지 진행을 검증합니다.

서버 실행 후 Python Playwright와 Chromium이 설치된 환경에서 브라우저 검증:

```sh
python3 tests/browser_smoke.py
```

`/usr/bin/chromium`을 사용합니다. 데스크톱/390px 모바일 화면, 선택, 집중 변경, 자동 저장 복원, 새 생애, 기록 보관, 내려받기를 검사합니다. 결과 이미지는 `/tmp/r1-checks`에 생성합니다. `GAME_URL`, `GAME_ARTIFACTS` 환경 변수로 주소와 출력 경로를 바꿀 수 있습니다.

## 구조

- `index.html`, `src/style.css`: 반응형 한국어 화면
- `src/data.js`: 지역·정권·직업·집중·실제 연표
- `src/events.js`: 조건별 가상 개인 생활 사건
- `src/engine.js`: 시드 기반 무작위 생애·능력·경제·관계·사망
- `src/app.js`: 렌더링·자동 시간·저장·기록·도움말
- `tests/`: 엔진 테스트와 브라우저 smoke test

프레임워크와 빌드 단계 없이 ES 모듈로 구성했습니다. 콘텐츠를 추가하려면 위 데이터 파일에 시대·지역의 근거 및 자격 조건과 함께 항목을 늘릴 수 있습니다.
